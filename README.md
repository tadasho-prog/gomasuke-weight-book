# ごますけ体重手帳 — SideStore 配信元

ゴールデンハムスター「ごますけ」の体重を記録するアプリを、家族2人の iPhone に配るための置き場です。

## SideStore に追加する

SideStore → **Sources** タブ → 右上の「+」 → 下の URL を貼る

```
https://raw.githubusercontent.com/tadasho-prog/gomasuke-weight-book/main/apps.json
```

追加すると Browse に出てきます。更新があるときは My Apps に Update が出ます。

## このリポジトリにあるもの

| ファイル | 中身 |
|---|---|
| `apps.json` | SideStore が読む配信情報（バージョン・ダウンロード先） |
| `icon.png` | 配信画面に出るアイコン |

アプリ本体（`.ipa`）は Releases に置いています。ソースコードはここには含まれていません。
